# MK Hunting

Complete hunting system: zones, server-side wildlife, skinning minigame, hide quality, butcher, grill, blood samples, quests, trophies, live admin editor and a hunter tablet

**Latest version:** `1.0.3` · [Changelog](CHANGELOG.md) · [Releases](https://github.com/mkscriptss/mk_hunting/releases)

## Where to get it

MK Hunting is a paid FiveM resource by **MK Scripts**, delivered through the Cfx.re Asset Escrow.
Buyers download every update from [portal.cfx.re](https://portal.cfx.re) → Granted Assets.

## Update check

This repository holds the release history only – no source code. When the resource starts, the server console
tells you if a newer version is published here (turn it off with `set mk_versioncheck false` in server.cfg):

```
[mk_hunting] update available: v1.0.0 -> v1.0.1 https://github.com/mkscriptss/mk_hunting/releases/tag/v1.0.1
```
